# Codex activation record

This filename is retained for links from older project documentation. The
machine-specific activation packet has been removed from the publishable source
because it contained local paths, installation hashes, and one workstation's
configuration history.

Use [INSTALLATION.md](INSTALLATION.md) for the reproducible activation and
rollback contract. Live installation still requires an explicit user-approved
step; building or cloning the repository does not authorize configuration
changes, a Codex restart, or hook trust.
