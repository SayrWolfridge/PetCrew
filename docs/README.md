# Документация PetCrew

PetCrew состоит из пользовательского приложения, локального Core и адаптеров
провайдеров. Начинать лучше не с архитектуры, а с того вопроса, который вы
сейчас решаете.

## Пользователю

- [Что такое PetCrew и зачем он нужен](USER_GUIDE.md) — идея продукта,
  основные понятия и повседневный сценарий.
- [Как появляются новые котики](ADDING_AGENTS.md) — новые задачи, субагенты,
  проекты, провайдеры и граница визуальных питомцев.
- [Настройки](SETTINGS.md) — все доступные элементы управления, значения по
  умолчанию, хранение и восстановление.
- [Сборка, подключение и откат](INSTALLATION.md) — техническая установка из
  исходников и безопасная активация адаптеров.

## Текущий статус распространения

Исходники, тесты и процедура сборки готовы. Публичного установщика и
автоматической пользовательской установки пока нет. Сборка репозитория сама по
себе не меняет Codex, OpenCode, автозапуск Windows или уже установленные
плагины.
