# Настройки PetCrew

Настройки Monitor сохраняются локально и восстанавливаются при следующем
запуске. Они меняют только представление и локальную историю прочитанного — не
поведение агентов и провайдеров.

## Быстрые элементы управления

| Элемент | Что делает | Значение по умолчанию |
| --- | --- | --- |
| `↗` | Переносит окно в правый верхний угол самого маленького подключённого экрана | Только по явному клику |
| `A−` / `A+` | Переключает три размера текста | Крупный (`large`) |
| `Список` | Показывает карточки одной вертикальной колонкой | Включён |
| `Плитки` | Раскладывает те же полные карточки в доступные колонки | Выключен |
| `☀` | Переключает тёмную и светлую тему | Тёмная |
| `⚙` | Открывает источник, глубину истории и настройки демо | Закрыта |
| `×` | Закрывает только окно Monitor | — |

Котик и заголовок можно использовать для перетаскивания окна. Размер меняется
за правый нижний угол.

## Источник карточек

В настройках доступны два источника:

- **Живые** — полный снимок PetCrew Core. В собранном desktop-приложении это
  основной режим.
- **Демо** — локальный тестовый набор данных для проверки интерфейса без
  Codex/OpenCode.

Демо не отправляет события провайдеру и не смешивается с живыми карточками. В
нём можно выбрать 1, 3 или 10 агентов, запустить сценарий, поставить его на
паузу и сбросить.

## Недавние прочитанные результаты

Можно хранить в видимом списке:

- `0` — не показывать прочитанный хвост;
- `5`, `10`, `20` или `50` последних прочитанных результатов.

По умолчанию показываются `10`.

Эта настройка не скрывает:

- работающих и планирующих агентов;
- агентов, ожидающих ответа или разрешения;
- заблокированные задачи и ошибки;
- непрочитанные завершения.

Нормальная ёмкость локального состояния — 100 карточек. Если одни защищённые
карточки превышают эту ёмкость, PetCrew честно показывает переполнение и не
удаляет важные записи ради красивого числа.

## Отметки прочтения

Это действия, а не постоянные настройки:

- `✓ Прочитано` — одна терминальная карточка;
- `Прочитать все` — все непрочитанные терминальные результаты команды;
- `Прочитать субагентов` — только непрочитанные терминальные карточки с
  `parent_agent_id`.

Активные, ожидающие и заблокированные карточки эти действия не меняют.

## Положение окна

PetCrew сохраняет внутренний размер окна, внешнюю позицию и имя монитора. На
старте он восстанавливает прямоугольник только если тот остаётся достаточно
видимым на одном из подключённых экранов.

Если сохранённый монитор исчез или координаты невалидны, приложение выбирает
безопасное видимое положение. Кнопка `↗` выполняет отдельное явное возвращение
на самый маленький экран и сразу сохраняет новый прямоугольник.

## Где хранятся настройки

Файл текущего пользователя:

```text
%LOCALAPPDATA%\app.petcrew.overlay\settings.json
```

Текущая схема хранит:

```json
{
  "schema_version": 1,
  "text_size": "large",
  "card_layout": "list",
  "theme": "dark",
  "recent_completed_limit": 10,
  "window": null
}
```

После первого перемещения `window` содержит координаты, размер и имя монитора.
Запись выполняется атомарно. Не следует редактировать файл во время работы
PetCrew.

Если файл повреждён или версия схемы неизвестна, приложение использует
безопасные значения по умолчанию. Некорректное положение окна отбрасывается
отдельно и не должно стирать остальные предпочтения.

Для ручного сброса сначала закройте Monitor, затем **переместите**
`settings.json` в резервную папку. На следующем запуске PetCrew создаст
настройки по умолчанию. Удалять файл без резервной копии не требуется.

## Чего в настройках пока нет

- выбора визуального котика;
- звуков и системных уведомлений;
- языка интерфейса;
- фильтров по проекту или провайдеру;
- ручного создания карточек;
- управления автозапуском Core/Monitor;
- управления агентами и разрешениями.

Автозапуск и подключение адаптеров относятся к установке, а не к настройкам
Monitor: [INSTALLATION.md](INSTALLATION.md).
