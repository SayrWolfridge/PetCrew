# Security policy

PetCrew is local-only by design. Please do not include prompts, transcripts,
credentials, local secrets, private task identifiers, or machine-specific
runtime state in a public issue.

For the implemented trust, transport, persistence, and provider boundaries, see
[docs/SECURITY.md](docs/SECURITY.md).

If a security report would expose private data, contact the maintainers through
a private channel before opening a public issue. A dedicated disclosure address
has not yet been published.
